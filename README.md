# Your-Childhood-Ruined-AI-v2.0-
Your Childhood Ruined AI v2.0 🧸💀

Taking wholesome childhood innocence and giving it cold, hard existential parody.

Your Childhood Ruined AI v2.0 is an interactive multimodal web studio powered by the Google Gemini API. It transforms beloved childhood fairy tales, cartoons, and storybooks into dark, witty, satirical parodies—complete with vintage book cover previews, downloadable retro cards, voice narration, suspect interrogations, and cursed merchandise pitches.

🌟 Key Features

📖 Satirical Book & Dossier Generator

Deconstructs wholesome cartoons into cynical parodies across 4 distinct angles:

Vintage Parody Book: Classic "Little Golden Book" style satirical title and rhyming existential synopsis.

Forensic Noir Case: Hardboiled 1940s cold-case detective breakdown.

Unhinged Conspiracy: Red-string corkboard government experiments and simulation glitches.

Corporate Dystopia: Shareholder liquidation reports, unpaid internships, and OSHA violations.

Customizable Cynicism Intensity Slider (from mild cheeky parody to total existential dread).

🎨 AI Cover Artwork Illustrator (gemini-3.1-flash-image)

Automatically paints visual parody book covers in your choice of artistic styles:

Vintage 1960s Little Golden Book watercolor

1940s Noir Graphic Novel with dramatic shadows

1980s Retro Cartoon Frame / VHS animation

🎙️ Studio Voice Narration (gemini-2.5-flash-preview-tts)

High-fidelity Gemini voice actors (Algenib, Puck, Charon, Kore, Zephyr).

Converts raw PCM16 signed audio streams into playable in-browser WAV audio, with automatic fallback to native speech synthesis if offline.

🕵️ Suspect Interrogation Room (gemini-3-flash-preview)

Step under the interrogation lamp to cross-examine the corrupted childhood character in real time.

Characters plead the Fifth, justify OSHA violations, blame their animators, and reveal deeper secrets across a multi-turn conversational chat.

📄 Leaked Studio PR Apology & Cursed Merch Pitch

Leaked PR Statement: Generates a desperate, legally-vetted press release from the franchise's corporate studio attempting to spin the leaked lore.

Unsafe Toy Pitch: Generates an unethical, legally questionable corporate tie-in merchandise pitch.

🎛️ Agent Studio & Engine Dashboard

Model Switcher: Toggle between Gemini 3 Flash (instant witty responses) and Gemini 2.5 Pro (deep literary prose and lore deconstruction).

Agent Personas: Select between Cynical Satirist, Clinical Psychoanalyst, Noir Gumshoe, or Unhinged Podcaster.

Fine-Tuning: Temperature/Chaos slider (0.2 dry to 1.2 fever dream) and custom system directive overrides.

Google Search Grounding: Toggle live web searches to ground parodies in real-world franchise scandals and creator lawsuits.

Zero-Key Offline Sandbox: Test mock procedural satire immediately without calling external APIs.

💾 The Childhood Vault & Card Export

Local Storage Vault: Saves up to 25 generated ruins directly inside the browser session—no external backend required.

PNG Card Export: Custom HTML5 canvas engine renders and downloads a print-ready retro satirical book cover card.

🚀 Quick Start / Deployment to GitHub Pages

Because the app is built as a self-contained single-page application, deploying it takes less than two minutes:

Create a GitHub Repository: Name it your-childhood-ruined-v2 and set it to Public.

Add index.html: Copy the entire code of index.html into the root of your repository and commit it to main.

Add README.md: Commit this file to your repository.

Enable GitHub Pages:

In your repo, go to Settings > Pages.

Under Build and deployment > Source, choose Deploy from a branch.

Select branch main and folder /(root), then click Save.

Your app is live at:

https://<your-github-username>.github.io/your-childhood-ruined-v2/


🔑 API Key & Privacy

Safe Client-Side Architecture: Do not hardcode your Gemini API key in the source code.

Users can click Agent Dashboard > API Key & Safe Fallback on the live site to enter their personal Google AI Studio key.

Keys are saved solely in the user's private browser localStorage and never transmitted to any third-party server.

Zero-Key Sandbox: Don't have an API key? Simply check Offline Satire Sandbox in the settings or click Generate Sample to test the app instantly.
